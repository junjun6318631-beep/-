# 크롬 다이노 게임 자동 플레이 봇

인터넷이 끊겼을 때 나오는 크롬 공룡(T-Rex) 게임을 **대신 플레이해 주는 도구**입니다.
화면에 게임을 띄워 둔 채로 실행하면, 알아서 점프하고 숙이면서 계속 달립니다.

두 가지 방법을 넣어 두었습니다.

| | 방법 ① 콘솔 JS 봇 | 방법 ② 화면 인식 파이썬 봇 |
|---|---|---|
| 설치 | 필요 없음 | `pip install -r requirements.txt` |
| 정확도 | 게임 내부 값을 직접 읽어 오차 0 | 화면 픽셀로 읽어 약간의 오차 |
| 쓰는 곳 | 크롬 다이노 게임 | 콘솔을 못 쓸 때, 다른 다이노 클론, 다른 브라우저 |

> 게임 속도를 늦추거나 가속을 끄는 **치트는 넣지 않았습니다.** 순수하게 판단력으로 버팁니다.
> (다이노 게임은 시간이 갈수록 빨라지고 최고 속도에서 멈추는데, 그 뒤로도 계속 살아남습니다.)

---

## 방법 ① 브라우저 콘솔에 붙여넣기 (권장)

1. 크롬에서 오프라인 페이지를 엽니다. (인터넷을 끊거나 주소창에 `chrome://dino`)
2. `F12` (맥은 `⌘⌥I`) → **Console** 탭.
3. 콘솔이 붙여넣기를 막으면 **`allow pasting`** 을 입력하고 Enter.
4. [`js/dino-bot.js`](js/dino-bot.js) 파일 내용을 **통째로 복사해 붙여넣고** Enter.

붙여넣는 즉시 자동으로 플레이를 시작하고, 화면 오른쪽 위에 점수·속도·판단이 뜹니다.

```js
DinoBot.stop()      // 멈추기
DinoBot.start()     // 다시 시작
DinoBot.cfg.margin  // 현재 안전 마진(px) 보기
DinoBot.stats       // 점수 / 최고 기록 / 죽은 횟수
```

### 북마클릿으로 한 번에 실행하기

매번 붙여넣기 귀찮으면 [`js/dino-bot.bookmarklet.txt`](js/dino-bot.bookmarklet.txt) 의 내용을
북마크의 **URL** 로 저장해 두세요. 게임 화면에서 그 북마크를 누르면 바로 시작합니다.
(북마클릿 안에 코드가 통째로 들어 있어 **인터넷이 끊긴 상태에서도** 동작합니다.)

## 방법 ② 화면을 보고 대신 눌러 주기 (파이썬)

```bash
pip install -r requirements.txt
cd python
python3 -m dino_bot.main --debug
```

게임 창을 앞에 띄우고 **한 번 클릭해 포커스를 준 상태**로 실행하세요. 봇이 화면을 캡처해
장애물을 읽고 스페이스/아래키를 눌러 줍니다. 멈추려면 `Ctrl+C`.

```bash
python3 -m dino_bot.main --calibrate    # 게임을 제대로 찾았는지만 확인 (키 입력 없음)
python3 -m dino_bot.main --dry-run      # 판단만 하고 키는 누르지 않음
python3 -m dino_bot.main --region 100 300 1200 400   # 게임 영역을 직접 지정
python3 -m dino_bot.main --scale 2 --margin 10       # 배율·안전 마진 직접 지정
```

- 자동 탐지는 **지평선과 공룡**을 찾아 게임 영역과 화면 배율을 스스로 계산합니다.
  실패하면 `--calibrate` 로 인식 결과(`dino-bot-calibration.pgm`)를 확인하고
  `--region` / `--scale` 로 지정해 주세요.
- 밤 모드(배경이 검게 반전되는 구간)는 자동으로 처리합니다.
- 죽으면 알아서 다시 시작하고, 오래 못 버텼으면 안전 마진을 넓힙니다.
- 맥에서는 **손쉬운 사용 / 화면 기록** 권한을 터미널에 줘야 캡처와 키 입력이 됩니다.
  리눅스는 X11에서 동작합니다(Wayland는 캡처·입력이 막힐 수 있습니다).

## 어떻게 판단하나

점프 타이밍을 "속도 × 상수" 같은 손으로 맞춘 임계값으로 정하지 않습니다.
매 프레임 **게임 물리를 그대로 예측**해서 고릅니다.

1. **그냥 달려도 되는가?** — 지나갈 수 있으면 아무것도 하지 않습니다 (높이 나는 새).
2. **숙이면 되는가?** — 되면 아래키를 누르고 있습니다 (가운데 높이의 새).
3. **뛰어야 한다면 언제?** — "지금 뛰면 넘는가", "조금 더 기다려도 넘는가"를 각각
   시뮬레이션해서, **넘을 수 있는 마지막 순간**에 뜁니다. 너무 일찍 뛰면 장애물 앞에
   착지해서 다시 뛸 수 없기 때문입니다.
4. **그 다음 장애물까지 본다** — 점프는 약 35프레임을 묶어두는 결정이라, 착지한 뒤
   다음 장애물을 넘을 시간이 남는지까지 확인하고 뜁니다. 남지 않으면 더 일찍 뛰거나,
   공중이라면 아래키로 **빠르게 착지**해 시간을 법니다.

여기에 안전장치 두 개를 얹었습니다.

- **프레임 밀림 보정** — 화면이 버벅이면 그만큼 장애물이 더 다가온 것으로 보고
  보수적으로 판단합니다. 실제 틱 간격을 재서 자동으로 반영합니다.
- **안전 마진 자동 보정** — 죽으면 마진을 넓히고, 충분히 오래 달리면 다시 좁힙니다.
  JS 봇은 이 값을 `localStorage` 에 저장해 다음에도 이어서 씁니다.

새는 높이에 따라 셋으로 갈립니다. 높이 나는 새(yPos 50)는 그냥 달리고,
가운데(75)는 숙이고, 낮은 새(100)는 뛰어넘습니다. 이 판단도 상수가 아니라
공룡·장애물의 충돌 박스를 직접 비교해서 정합니다.

## 테스트

브라우저 없이 검증할 수 있게, 크롬 원본(`offline.js`)의 물리·장애물 생성·충돌 박스를
그대로 옮긴 시뮬레이터를 JS와 파이썬 양쪽에 넣어 두었습니다.

```bash
npm test                                   # JS 봇 17종
python3 -m unittest discover python/tests  # 파이썬 41종
```

파이썬 쪽에는 화면 인식까지 확인하는 테스트가 들어 있습니다. 시뮬레이터 상태를 실제
게임과 같은 그림으로 그린 다음, **그 그림을 캡처 → 인식 → 판단 → 키 입력** 순서로
통과시켜 다시 시뮬레이터에 넣습니다. 즉 배율 계산과 장애물 읽기까지 함께 검증됩니다.

측정 결과(시뮬레이터 기준):

| 환경 | 결과 |
|---|---|
| JS 봇, 시드 30개 × 10만 프레임 | 300만 프레임(약 14시간 분량) 무사고 |
| JS 봇, 프레임 간격 흔들림 + 틱 4% 누락 | 180만 프레임 무사고 |
| JS 봇, 틱 15% 누락 | 180만 프레임 무사고 |
| 파이썬 판단부, 관측 오차 ±3px | 40만 프레임 무사고 |
| 파이썬 판단부, 오차 + 틱 25% 누락 | 39만 프레임 중 1회 사망 |
| **진짜 크롬 다이노 게임**(헤드리스 크로미움) | 5분 무사고, 최고 속도 도달 |

시뮬레이터만 믿지 않으려고, 진짜 게임 코드에 봇을 붙여 돌려 보는 경로도 넣었습니다.

```bash
pip install playwright
python3 tools/verify-real-game.py --seconds 120
```

이 검증에서 실제로 문제를 하나 잡았습니다. 크롬 원본은 점프 속도 상수 이름에 오타가
있어서(`INIITAL_JUMP_VELOCITY`) 봇이 값을 읽지 못하고 있었고, 예측이 어긋난 채
"부딪히기 직전에 뛰는" 상태로만 굴러가고 있었습니다. 지금은 두 이름을 모두 받고,
아예 못 읽으면 원본 상수로 대신합니다.

## 파일

```
js/dino-bot.js                 콘솔에 붙여넣는 봇 (이것만 있으면 됩니다)
js/dino-bot.bookmarklet.txt    위 파일의 북마클릿 버전
js/build-bookmarklet.js        북마클릿 생성 (node js/build-bookmarklet.js)
js/sim/dino-sim.js             크롬 원본 물리를 옮긴 시뮬레이터 (테스트용)
js/test/bot.test.js            JS 검증

python/dino_bot/policy.py      판단 로직 (표준 라이브러리만)
python/dino_bot/vision.py      화면 캡처·게임 영역 탐지·장애물 읽기
python/dino_bot/keys.py        키 입력
python/dino_bot/main.py        실행 진입점
python/sim/dino_sim.py         파이썬 시뮬레이터 (테스트용)
python/tests/                  판단·화면 인식·전 과정 검증
```

## 알아 둘 점

- 콘솔 JS 봇은 크롬 다이노 게임의 내부 객체(`Runner.instance_`)를 읽습니다.
  구조가 크게 바뀐 버전이나 다른 클론에서는 동작하지 않을 수 있고, 그때는 파이썬 봇을 쓰세요.
- 파이썬 봇은 **화면에 게임이 가려지지 않게** 띄워 두어야 하고, 키 입력이 게임 창으로
  가야 하므로 실행 후 게임 창을 클릭해 두세요.
- 게임 속도는 최고치(13)에서 멈춥니다. 그 뒤로는 사실상 무한히 달릴 수 있지만,
  화면이 심하게 버벅이면(초당 30프레임 이하로 떨어지면) 봇도 반응할 시간이 모자랍니다.
